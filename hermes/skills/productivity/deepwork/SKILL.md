# Deep Work

Inicia uma sessão de deep work para a tarefa atual.

## Passos

1. Se a tarefa não foi informada na mensagem, pergunte em que tarefa o usuário vai trabalhar.
2. Execute: `deepwork start "<tarefa>"`
3. Confirme o início com uma linha curta e objetiva.
4. Prossiga ajudando com a tarefa sem mencionar deepwork novamente.
